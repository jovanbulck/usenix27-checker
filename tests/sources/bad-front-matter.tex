% =============================================================================
% bad-front-matter -- the reserved front-matter space is largely removed.
%
% usenix.sty typesets the title block as a fixed "\vbox to 2.5in", so with the
% 1" top margin the body (its abstract) starts 3.5" down page 1. Redefining
% that box shorter pulls the whole body up and gains lines without touching a
% single margin. Here it is shrunk to 0.9in, so the body starts ~1.9" down.
%
% The checker measures where the body starts, so it catches this whether or
% not an author block is present. Below 2.2" the squeeze is unmistakable and
% errors outright; see bad-front-matter-mild for a subtler pull-up.
%
% Expected checker outcome: FAIL with error [front-matter].
% =============================================================================

  \par
  \vspace*{\fill}}}
\makeatother
