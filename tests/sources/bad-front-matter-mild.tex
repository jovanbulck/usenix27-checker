% bad-front-matter-mild -- the reserved front-matter space is made smaller.
%
% usenix.sty typesets the title block as a fixed "\vbox to 2.5in", so with the
% 1" top margin the body (its abstract) starts 3.5" down page 1. Redefining
% that box shorter pulls the whole body up and gains lines without touching a
% single margin. Here it is shrunk to 1.4in, so the body starts ~2.4" down.
%
% The checker measures where the body starts, so it catches this whether or
% not an author block is present. Even this moderate pull-up is an error: the
% reserved area has a fixed height, so a body above it can only come from
% reclaiming that space. bad-front-matter shrinks it further still.
%
% Expected checker outcome: FAIL with error [front-matter].
% =============================================================================

  \vspace*{\fill}}}
